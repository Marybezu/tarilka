# Тарілка · Tarilka

**Приватний офлайн-трекер харчування для Android з науковою базою продуктів, звичками без осуду й локальним ШІ.**
Українська та англійська. Безкоштовно, відкритий код, без реклами й акаунтів.

> **Статус: тестова версія.** Перед оновленням робіть резервну копію (Опції → Дані). Відгуки й помилки: Опції → Про застосунок → «Написати відгук» або вкладка [Issues](../../issues).

## Чому Тарілка

- 🔒 **Приватність за замовчуванням.** Дозволу на інтернет немає, тож застосунок фізично не може нічого надіслати. За замовчуванням не запитує жодного дозволу. Дані лише на телефоні, хмарну копію вимкнено. Резервна копія — за вашою дією, за бажанням зашифрована паролем (AES-256).
- 🔬 **Наукова база офлайн.** 594 продукти: числа USDA [FoodData Central](https://fdc.nal.usda.gov/) копіюються автоматично, біля кожного продукту видно джерело.
- 🥟 **Українські страви:** борщі, вареники, сирники, голубці, банош, олів'є та ще ~80, розраховані з інгредієнтів за відкритим рецептом.
- 🌱 **Звички без осуду.** Кольорові плашки рахуються самі: овочі й фрукти, солодке, пізня їжа, алкоголь, фастфуд. За бажанням — сон, «чому я їм», тренування, кишківник. Стрілки тенденцій, доказові поради (ВООЗ, КПТ), самоперевірка AUDIT-C.
- 🤖 **Локальний ШІ (Gemma 4), за бажанням.** Розпізнає їжу на фото (з урахуванням розміру тарілки й ваших виправлень), дає поради на день і підсумки за тиждень, місяць, рік. Працює повністю на телефоні, фото видаляється після аналізу.
- 📒 **Щоденник:** прийоми їжі, рідина (зокрема напої й супи), вага, кроки з ціллю й графіком, нотатки, історія, свої продукти й страви, експорт у CSV.
- 🌸 **Цикл, за бажанням.** День циклу, приблизна дата наступного, пояснення коливань ваги й апетиту. Не метод контрацепції.
- 🔔 **Нагадування, за бажанням:** прийоми їжі, вода, сон, цикл, підсумок тижня. На заблокованому екрані без подробиць.

## Встановлення

1. Завантажте `tarilka-….apk` зі сторінки **[Releases](../../releases/latest)** і відкрийте його на телефоні.
2. Для автооновлень додайте цей репозиторій в [Obtainium](https://obtainium.imranr.dev/).
3. **ШІ (необовʼязково):** Опції → «ШІ на телефоні» → «Завантажити модель» (`gemma-4-E2B-it.litertlm`, ≈2,6 ГБ, завантажує браузер), потім «Обрати файл моделі».

## Прозорість

- **Дозволи:** інтернету немає, і збірка зупиняється, якщо він з'явиться. Датчик кроків, Health Connect (кроки, сон, цикл — лише читання; їжа, вода, вага — запис) і сповіщення запитуються, лише коли ви вмикаєте відповідну функцію.
- **База:** `scripts/food_sources/` (опис USDA, етикетки, рецепти страв) і `scripts/build_foods.py`.
- **Збірка:** APK збирається з цього коду в GitHub Actions; журнал публічний.
- **Як створено:** код і база написані за допомогою ШІ (Claude, Anthropic) під керівництвом і з тестуванням авторки; рішення щодо функцій і приватності — людські.
- **Застереження:**
  - якщо ввімкнути запис у Health Connect, дані побачать застосунки, яким ви там дали доступ;
  - копія без пароля не зашифрована;
  - ШІ оцінює порції приблизно, тож перевіряйте грами;
  - поради загальні й не замінюють лікаря чи дієтолога.

Kotlin · Jetpack Compose · Room · [LiteRT-LM](https://github.com/google-ai-edge/LiteRT-LM). Ліцензія MIT.

### English

**Tarilka** is a private, offline food tracker for Android. **Test version** — please back up before updating; feedback via Options → About → Send feedback or [Issues](../../issues).

- No internet permission, no accounts, no analytics. Data stays on the phone; optional password-encrypted backups.
- 594 foods: USDA lab values copied automatically, plus Ukrainian dishes calculated from open recipes.
- Non-judgmental habit badges (vegetables, sweets, late eating, alcohol, fast food; optional sleep, why I eat, workouts, bowel) with trends and evidence-based tips.
- Optional on-device Gemma 4: plate photos, daily advice, week/month/year summaries.
- Diary, fluids, weight, steps with a goal, notes, history, own recipes; optional cycle tracking (not contraception) and reminders.
- Code and database were written with AI assistance (Claude, Anthropic), directed and tested by the author.

Install the APK from [Releases](../../releases/latest). MIT licence.
